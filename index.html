Autonomous Vehicles

Tesla FSD Integration

When MBTA capacity hits critical thresholds, the platform automatically dispatches Tesla autonomous vehicles to fill the gap — creating a seamless last-mile and overflow solution.

🧠

AI Dispatch Engine

When a route exceeds 80% crowding, the system calculates the nearest available Tesla AV units and dispatches them to relief stops automatically via the Fleet API.

📡

Real-Time MBTA Sync

AVs receive live MBTA departure feeds. If a train is delayed ≥ 4 min, Tesla vehicles are pre-positioned at the affected station to intercept passengers.

🛣️

Optimal Route Handoff

The Dijkstra engine computes the fastest path; if transit is slower, it reroutes passengers to an AV pick-up point with a single tap in the companion app.

🔋

Fleet Health Monitor

Battery levels, location, and ETA for every AV unit tracked in real time. Low-battery units are swapped automatically before peak hours begin.

Architecture

How It Works

A four-layer stack from raw MBTA data to AV dispatch — fully automated.

📥

Ingest

MBTA V3 API streams stop arrivals, departures, crowding sensors, and vehicle positions every 10 seconds.

⚙️

Analyse

The Python engine builds a weighted graph, runs Dijkstra routing, and scores every route for delay and crowding anomalies.

🤖

Recommend

AI rules engine generates headway changes, signal priority requests, and AV dispatch orders within 200 ms of detecting an issue.

🚗

Dispatch

Approved actions flow to the Tesla Fleet API, MBTA operations centre, and the passenger app simultaneously — zero manual steps.
